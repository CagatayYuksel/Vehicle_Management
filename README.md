# Vehicle_Management

Bu proje araç ve filo yönetim sistemi için kurulmuştur. Projede araçlar, sürücüler, bakımlar, cezalar, sigorta ve kaskolar, evrak işlemleri, ödeme bilgileri, kullanıcı kayıtları, izlenen rota gibi bilgiler takip edilecek ve bir web arayüzünde çalışacak şekilde hayata geçirilecektir.
